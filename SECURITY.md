# Security policy

## Supported versions

Security fixes are provided for the newest published release.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier versions | No |

## Report a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/tednv/VoxBridge-Compose/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include:

- The affected version and operating system
- The smallest safe reproduction you can provide
- Expected and observed behavior
- Security impact and any known mitigations

Do not submit credentials, access tokens, private recordings, transcript
contents, unredacted diagnostics, local usernames, machine names, network
addresses, or absolute filesystem paths. Replace sensitive values with neutral
placeholders.

You should receive an initial response within seven days. Please allow time to
investigate and prepare a coordinated fix before public disclosure.

## Scope

Reports about VoxBridge Compose and its packaging belong here. Vulnerabilities
in a third-party dependency or service should also be reported to that upstream
project when appropriate. The separately maintained VoxBridge runtime has its
own repository and security history.
